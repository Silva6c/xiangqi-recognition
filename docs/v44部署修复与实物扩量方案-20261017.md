# v44 方案：部署口径修复（QAT）+ 实物域扩量（2026-10-17 深夜）

> 定位：v43 收官后的研究轮产物。两条正交主攻——A 线治"部署口径伤"（int8 bench 2/10 被九轮自动报告掩盖），B 线治"实物域最后缺口"（22 错 vs nano 3）。两个 Explore 子代理事实卡 + 主线对照实验矩阵收敛，本文是施工依据。红线：**切勿越来越差**——所有改动带独立验证口径，现役产物零覆盖。

## 一、A 线：int8 部署口径修复

### 1.1 问题定性（子代理事实卡 + 主线实验）

- **掩盖机制**：自动报告 bench 段只报 fp32 口径，int8 只出一致率（0.96+）；int8 bench 明细躺在 eval_bench.json 里不上报告不设门。历史全貌：v35 0/10、v38a 1、v39 4、v40 3、v41 3、v42 **1**、v43 2（同轮 fp32 5~8）。
- **数学必然**：bench 是模型自身对抗集（fp32 才 7/10），0.96 一致率摊到 90 格 ≈ 每帧 3-4 格分歧，足以毁掉"全对"口径。
- **域缺口**：校准集 = 渲染 100 + roboflow 实物 100，**App 截屏域（bench 所在域）从未进过校准**；export.py `_load_real_frames` 单源 return bug 使逗号多源列表永远只吃第一个。
- **损伤分布**（主线实测）：int8 比 fp32 新增 8 错**全部集中底行 (9,x)**——先验拉扯区（(9,7) R/N、(9,0) c/R、(9,8) ./R 边际格密集），量化噪声一推就翻边。
- **重磅旁证**：端上 `CLS_MODEL` 仍是 nano_v3——GridHead 从未上机，int8 2/10 是切换部署前的必修课。

### 1.2 对照实验矩阵（v43/gen_best.pt，实验产物全落 .cache 不覆盖现役）

| 配置 | bench int8 | 四轴 vs 现役 int8 | 判定 |
|---|---|---|---|
| 现役基线（200 帧 2 源） | 2/10 | — | 问题现状 |
| E1 校准 600 帧单源扩容 | 4/10 | style **-0.6**，piece +0.3 | 温和但 style 有损 |
| E2 600 帧 3 源均衡 | 4/10（总错 9） | style -0.55 | 同上 |
| E3 = E2 + act-sym | **6/10**（总错 5 = fp32） | style **-1.4** / angle -0.7 | bench +4 是拿四轴换的，**否决** |
| E4 = E3 + reduce-range | 6/10 | 同 E3 略差 | reduce-range 无增益 |
| E5 act-sym + 1000 帧 | 4/10（总错 10） | 全轴最差 | **扩容过头反伤**（MinMax 范围被极端帧撑大） |
| fp16（5.86MB） | **7/10 = fp32 逐格全同** | 一致率 100% | **桌面延迟 37.2ms 超 30ms 红线**（CPU 无原生 fp16 kernel），需端上 NNAPI 实测 |

**结论**：校准/格式层的所有变体都在"重新分配量化噪声"，无一双赢。**正解 = QAT**（让模型在微调中适应量化网格），fp16+NNAPI 作真机备选。

### 2.2 可解锁增量与施工

- **abplc + fpt：25889 框 / 2318 图**（_do=đỏ 红 / _den=đen 黑，映射 vua→kK、tuong→bB、si→aA、ma→nN、xe→rR、phao→cC、tot→pP）；按全池 13.6% 帧入池率估 **+800~1200 帧**，abplc 整局图结构合法率应高于均值；贴片库候选 +数千格
- 拒收带实测复核：0.55~0.65 conf 带全库外推仅 ~284 枚（+7%）且是叠压坏片富集带——**conf 分档路线死心**（拒收大头是 argmax 失配 ~3.5 万格，降门槛收不进来）
- 新弹药登记（后续轮）：efbok 分类集 7190 枚现成贴片（folder 直读）；zfk 三材质实拍 28302 框（亚克力/不锈钢/木质——26 帧实物域没有的成像条件，需先核 14 类全名）；seq68 字类 24511 框（红黑需 teacher 判）

### 2.3 v44 训练轮设计

- 配方：init-from v43/gen_best + 数据池 = v43 九集 + **VN 扩容贴片池 v2**（重跑 parse→贴片管线，库预计 4045→8000+）；**VN 帧只走贴片路线**（几何一致性由渲染端成立——v42 整帧证伪教训延续）
- 三层防退化全延续：格级自证 conf 0.65 / --early-stop-patience 10 / human 选点健康监控
- **预注册判据**：
  - 核心：26 帧实物域 ≤20（v43 22，延续收窄；≥24 证伪）
  - 四轴 -0.5pt 防守 + bench fp32 ≥7 + total 42/39 不退
  - **新增部署口径门：bench_int8 ≥5**（A 线 QAT 产出，与 B 线判据正交）
  - 健康判据：human 选点不得 step 100 内崩溃见顶
