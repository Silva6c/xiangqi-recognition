# v47 方案：专业性能轮（2026-10-18 研究稿）

> 定位：用户拍板后 v47 转向——**放弃 int8 执念**（nano 本身就是 fp32 部署先例：
> 10.85MB/端上单线程 194ms 在用；GridHead fp32 11.7MB/桌面 12ms 快 11 倍，部署零
> 障碍），**int8 从部署判据降级为参考指标（gates 删除 int8 门）**，v47 主攻 fp32 口径
> 专业性能。证据：两份 Explore 事实卡（实物域扩采路径 + App/bench 靶向）。
> **点火权在用户。**

## 一、两份事实卡的关键结论（2026-10-18，含勘误）

### 1.1 勘误块（此前文档口径错误，本轮修正）

- **v46 bench_best 残余两错都在 (9,8)**（f6/f7 均 .>R）——v46b方案 §1.2 写
  "(9,7)+(9,8)" 有误；**v46b 实测残余 3 格全是 (9,7) R>N**（f6/f7/f8，此前写 2 格）。
  **(9,8) .>R 幻视已被 v2 反面证据灭掉**（跨 v46/v46b 双轮确认），(9,7) 三格才是
  真顽固。当前状态.md 同步勘误。
- **App 域 21 错中 14 格是评测噪声**（与 nano_v3 独立错误逐格重叠：f19×8、f21×4、
  f25×1、f17×1——两个互不相关引擎一致反对真值）——**纯模型真错仅 7 格**（红背排
  类内混淆 3 + 颜色双错 2 + 零星 2）。v37 时代的三簇结论已过时：红马→车×5 簇收敛
  到 1 格、绿描边漏检簇已灭、UI 遮挡格 0 错。
- **绿描边/UI 遮挡渲染仿真 v39 已实施**（renderer.py RIM_ALT 绿系 12% + 灰面板
  快速路径）——v46b 残余 7 真错零命中，加码边际收益≈0，不进 v47。

### 1.2 实物域画像（专业性能最大缺口）

- v46b real17 = **18 错 vs nano 3 错**（差 15 格）：**空格幻视 8 + 漏检 6 + 字形
  混淆 4**。幻视 8 格全是标准开局位反先验（f0 (9,7)(9,8)、f2 (9,0)(9,1)、f6 (0,1)、
  f11 (4,2)(4,3)、f16 (0,0)）——与 bench 顽固簇同族，**是单一机理的跨域表现**。
- 17 帧"实物域"实为三混合分布：木纹底 App 渲染残局图（多数）+ 街拍实体棋盘（少数，
  nano 领先的主因域）+ 挂板视频帧——同域扩采按此画像配关键词。
- App 域真错 7 格中红背排类内混淆（N>R/R>N/N>P）与字形有关——v39 红马定向的扩展
  面（馬/傌×車/俥 描边画风字形对）。

### 1.3 弹药与管线事实

- **空格反面证据泛化（两卡共同首靶）**：erase_by_bg 背景迁移擦除是唯一被证实灭过
  (9,8) .>R 的机制——从 bench 特例推广为跨域通用增广，直接打实物 8 格幻视 +
  bench (9,7) 同族 + App 空格误检。v1 池 (R,.) 904 曝光 4 倍未灭 (9,7) 反证：
  正面证据堆量此路不通，**反面证据（擦空）才是有效机制**。
- **爬虫同域扩采（v16 首战 +17pt 路线复现）**：crawl_photos.py 双引擎在位，老关键词
  饱和需新词（实体照片系 8 词+App 渲染系 2 词+英文系 3 词）；跨目录去重需预注入
  5 份旧 manifest；**26 帧源图 aHash 预去重=评测防泄漏闸（铁律）**；QC 走
  annotate_photo.py 伪标签整帧路径（现成，VN 式换子自证不适用——无框标注）；伪标签
  npz→patch_lib 转换 ~30 行即可并入 extra-lib。
- **VN 库已榨干**（33689 框全裁、QC 入库 25883、残余 K/k+拒片无价值）；zfk/efbok
  降权混入=备胎不主攻（v46b 已证同域-only 最优）。
- **bench 残余 (9,7) 三格的供给现状**：v1 (R,.) 904 + V18_BIAS 渲染 9% + v2 55——
  三路正面证据未灭；combo_shift v3 修正（函数体 5 处）价值=工具正确性+真域补量
  ≤30 红位，对 bench 直接收益低，作低成本配套。

## 二、v47 主攻（数据侧双弹，机制均为已验证路线的新应用）

### A 线：空格反面证据泛化（首靶，打实物 8 幻视 + bench/App 同族）

- **离线增广池**（照 bench_v2 先例，剂量可控不动训练核心）：.cache 脚本渲染底帧 →
  占子格 erase_by_bg 背景迁移擦除 → 标签同步置 0 → `data/erase_aug_v47.npz`。
- **擦除位分布**：红背排 (9,0)(9,1)(9,7)(9,8) + 黑对称 (0,0)(0,1)(0,7)(0,8) 热点
  加权 + 全盘随机格——每帧擦 1-2 格，目标 **6000-8000 帧**（v2 2164 已证剂量有效，
  泛化版加量 3 倍）。
- **双格 QC**（v2 同款）：擦除位 nano '.' conf≥0.5 + 邻格判定不变。

### B 线：爬虫同域扩采（真域注入，v16 路线复现）

1. crawl_photos.py 新方向爬取（--out 独立目录 photo_crawl_v47）：实体照片系
   "茶馆下棋/街头残局骗局/公园棋局实拍/木制象棋盘实拍/真人下象棋照片/棋友对弈围观/
   乡村棋摊/实木象棋" + App 渲染系 "象棋残局挑战/路边棋局残局" + 英文系
   "xiangqi street/chinese chess street game/xiangqi board photo"（13 词 ×~80）
2. 跨 manifest 去重预注入（5 份旧 manifest md5/aHash 合并载入，~20 行胶水）
3. **26 帧源图 aHash 预去重闸**（评测集永不入训铁律的执行动作）
4. annotate_photo.py 伪标签（board_thr 0.5）→ `data/real_photo_v47.npz`
5. 高置信格裁片 → patch_lib 转换 ~30 行 → `data/photo_crawl_patch_lib.npz`

### C 线：低成本配套

- combo_shift v3 修正（函数体 5 处，调用点不动）+ 池重生成（synth 2000 不变剂量）
- **shard v47 再生**：`--extra-lib "vn,photo_crawl_patch_lib" --tag
  real_rf_patch_transplant_v47`（同域律：不放 zfk/efbok）

### D 线：不进本轮

- int8（用户拍板放弃；gates 删除 int8 门，自动报告保留观测行）
- 绿描边/UI 遮挡加码（已实施、零命中）
- App 域 14 格噪声 IGNORE 化（评测口径变更，**待用户单独拍板**——影响所有历史数字
  可比性，不混训练轮）
- synth 正面证据堆量（v1 反证）
