# v67 方案：角点模型边缘化重设计（2026-10-26）

## 一、触发：用户洞察 + 事故分布级证据

用户指出："我们要找的并不是一个基础的角点，而是棋盘的边缘。"

QQ 象棋事故截图（ ornate 3D 棋盘）上 v4/v6 的 SimCC 原始 x 分布对照（256 affine 空间，
板左缘 ≈66px、右缘 ≈192px）：

| keypoint | v4 x top3 | v6 x top3 | 判定 |
|---|---|---|---|
| TL | 64(10.7) 64(10.3) 191(9.4) | 66(19.8) 66(19.7) 66(19.2) | 两者均=左缘 ✓ |
| **TR** | **190(10.3) 186 190** | **66(12.9) 67 68** | **v6 的 TR 被左缘完全霸占，右缘峰连前三都不进** |
| BL | 64 66 64 | 66 66 66 | 左缘 ✓ |
| BR | 190 190 67 | 192 192 193 | 右缘 ✓ |

**机理**：棋盘边缘（强竖线）在多个 keypoint 的 x 通道里都激发峰——TL/BL 选左缘正确，
BR 选右缘正确，但 **TR 的 x 回归头独立地选了左缘**。SimCC 把"棋盘边缘"这 4 个物理量
参数化成"4 个角点 × 8 条互不通气的一维回归"，**边缘这个概念在模型结构里不存在**：
TR.x 与 BR.x 本该锁同一条右边线，但结构上没有任何约束让它们对齐。v6 的 TR-x 通道
在该域（ornate 框+顶部头像面板，kst0.48 窄域训练）系统性地只学到左缘先验。

连锁反应（手机端实录吻合）：布局漂移 1358px → 重捕获 → v6 产出简并四边形（顶边 20px）
→ `detect_with_check` 的包围盒检查失效（简并四边形躲在正确 BR 撑起的 bbox 阴影里，
比例 0.89 照过）→ warp 畸形 → 幻影子力 → 级联改判 → 结构非法 → 服务端拒绝 → 死局。

## 二、设计：从"回归角点"到"回归边缘"

### 主案：box 参数化（中心+四边距+角度，四角由构造导出）

- 模型头：5 个一维 SimCC 式分布——**cx、cy、w、h、θ**（板中心、到四边距离、旋转角；
  θ 或以离散档位/小回归头承担，±35° 域）。
- 四角解码：`TL = c + R(θ)·(-w/2,-h/2)` 等四式——**四点自洽由构造保证**（对边平行、
  TR.x≡BR.x 恒成立），v6 式塌缩在结构上不可能。
- 网络主体不动（DW 骨干 633K 级），换头+换 GT 形态；`corner_data.py` 渲染 GT 从
  角点改推 box（角点→最小外接旋转矩形，解析自证不变）。
- **语义升级（用户洞察的第二层）**：检测目标=板的物理边缘（含木质外框的整块板）——
  强连续长特征，天然抗局部干扰（头像面板/bevel/棋子贴边）；格网交叉点降级为二级
  导出量：板缘锁定后，板内做竖线等差组+横线等差组（人工真值定案同款几何）校验并
  精修网格——frame 内缩随皮肤变化，等差组就是内缩的自动测量。

### 护栏（双保险，与主案独立）

- **结构一致性拒绝**：解码后校验 `|TR.x-BR.x|、|TL.x-BL.x|、|TL.y-TR.y|、|BL.y-BR.y|`
  与板宽高比例（SimCC 分布形态天然携带每 keypoint 置信，不一致即拒绝→宁 null→触发
  重捕获）。现有 bbox 检查替换为四边一致性检查（v6 简并四边形在此必被拦）。
- **边缘吸附精修（可选）**：候选四边形四边做梯度剖面吸附（Hough 等差思想），拉回
  小偏移。视 v7 精度决定是否上。

## 六、施工修订（2026-10-26 点火后回填）

1. **5 参数 → 6 参数（c, u, v 平行四边形）**：方案主案的 (cx,cy,w,h,θ) 旋转矩形
   无法表达训练域 kst 0~0.48 斜拍扭曲——kst 扭曲产出的是平行四边形（顶/底边倾斜
   可达 ~15°），旋转矩形拟合角点误差可达 50px@256。改为 6 参数：中心 c + 半宽向量
   u + 半高向量 v，四角 = c±u±v——对边平行的结构约束保留（v6 式角点各自塌缩仍
   结构性不可能），新增剪切自由度精确覆盖训练域。参数序 [cx,cy,ux,uy,vx,vy]，
   值域 BOX_LO/BOX_HI（cx/cy ∈ (0,256)、形状参数 ±128，全参数 0.5px/bin@256）。
2. **双头参数分家**：v64 SimCC 的 x/y 双头各有独立证据通路（行池化剖面→x、列
   池化剖面→y），6 参数按横向/纵向分家——x 头 (cx,ux,vx)、y 头 (cy,uy,vy)，
   每参数只在一处有分布头，避免双头同分布的弱信号拖累。输出契约 [1,3,512]×2。
3. **box 语义 = 格网区外接框**（A0/A8/J0/J8 四角，与 v64 角点语义一致）：端上
   warp450 几何零改动；格网最外侧线即屏幕域棋盘的强连续边缘——用户洞察
   "找的是边缘不是角点"的结构化落地（v6 事故根源是角点身份歧义，box 参数化
   后 u_x 的 GT 恒为半宽大正值，无"锁哪条边"歧义）。
4. **护栏落地**：塌缩（边长<8px@原图）+ 宽高比 0.5~2.2 + 面积 2%~120%（与旧
   boxPlausible 同域）+ 端上 boxDecode 内 256 空间同款。QQ 事故 v6 简并四边形
   （顶边 20px 躲 bbox 阴影）在 box 解码下以"真实顶边长"暴露，比例 0.05 必拦。
5. **模型规模**：403.8K / fp32 1.62MB（v64 633.6K 的 fc 头从 4×512×2 收窄为
   3×512×2），延迟预期持平或略降。
6. **真实池平行四边形残差闸**：RTMPose 伪标签四边形若明显非平行（相对残差 >
   3.5% 对角线长）剔除——box 参数化只覆盖平行四边形族。
7. **QQ 基准池落盘**：事故截图 v4 定位四角（目检对齐格网交叉点+全链路 89/90
   实证）存 corner_qq_basis.npz 作 v67 判据 GT（判线 ≤6px 平均）。
