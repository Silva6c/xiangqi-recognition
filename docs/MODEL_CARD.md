# Model Card — 中国象棋识别引擎三件套

> 发布物：`weights/` 三件套 fp32 ONNX。本卡面向使用者与评估者：用途、契约、成绩、
> **局限**、许可立场。研发过程与全部 FAIL 判决见 [docs/](docs/README.md)。

## 模型概览

| 权重 | 角色 | 架构 | 参数量 | 输入 | 输出 |
|---|---|---|---|---|---|
| `corner_simcc_v1.onnx`（v4 权重） | 棋盘定位：整屏帧 → 格网四角 | CornerSimCC：DW 骨干 + 一维 SimCC 双分布头 | 0.63M | [1,3,256,256]（长边方形窗，ImageNet 归一化） | x/y 各 [1,4,512]，argmax/512×256 |
| `gridhead_fp32.onnx`（r3_w085） | 棋子识别：warp 俯视图 → 90 格局面 | GridHead：DW 主干 + 格间注意力 + 占子辅助头 | 3.61M | [1,3,315,280]（RGB /255） | [1,90,15] logits |
| `cell_cls_fp32.onnx` | 级联仲裁：低置信格逐格重判 | cell_cls 三件套 | 0.64M | [90,3,48,48] | [90,15] logits |

推理编排（角点 → warp450 → 整板 → 级联 → 朝向正则）见
[android/README.md](../android/README.md) 与 [docs/技术文档.md](技术文档.md)。

## 训练数据类别概貌

- **渲染合成主力**：参数化棋盘渲染器（字体池 30+ 开源字体、几何域 ±35°/占比
  0.30~0.90/透视、ornate 宽木框/头像面板分支、UI 背景/遮挡/噪点），真值解析自证
  零标注；训练字体与考卷字体严格隔离（GEN_HOLDOUT）。
- **真实域注入**：录屏伪标签池（RTMPose 交叉验证清洗）、Roboflow 公开数据集人工
  标注（约 14 万框，CC BY 4.0）、实物贴片库（5.5 万枚裁片，三材质）。
- 数据本体与评测底片**不随仓库分发**；来源与许可逐项见
  [ATTRIBUTION.md](../ATTRIBUTION.md)，完整性指纹见
  [data-pools-sha256.txt](data-pools-sha256.txt)。

## 局限（明示，勿高估）

1. **街拍俯拍域是当前最明确短板**：40~50° 大透视实拍定位会失准（nano17 定位
   FAIL 3/17；photo 一致率仅 33.1%），端到端在该域不可依赖。
2. **ornate 木纹皮肤历史事故**：v6 权重曾在 QQ 象棋 ornate 域角点塌缩（简并四边形
   → 错误局面）；现役 v4 权重在该域经全链路验证安全，但 v67/v68 两次结构重设计
   均未超越 v4（box 路线精度天花板），该域泛化仍依赖域覆盖纪律——**训练配方勿回撤
   几何参数域**。
3. **评测成绩为特定考卷口径**：五套考卷参数封版预注册（screen30 seed 封版），
   更换考卷需重新对表；不同光照/奇葩棋盘皮肤（v55 前考古的 17 类钉子户已入渲染域，
   长尾仍存在）。
4. **识别≠对弈**：本引擎只输出局面；走子建议由接入方另行实现（合规红线：不自动
   走子、无点击注入）。
