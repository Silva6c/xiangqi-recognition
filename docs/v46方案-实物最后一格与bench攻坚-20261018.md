### 1.2 bench 顽固簇根因（Explore 事实卡 A）

- **三轮错帧轨迹**（gen_fp32 口径 frames_err）：顽固帧=f6(case09)、f7(case10) 三轮
  全错，半顽固 f8(case11)（v44/v45）；单帧错格数 v43→v45 = 3→2→1 递减未归零
- **根因=右背排角格布局先验**：顽固帧底行 FEN 均为 `c1BAKABR1`（车在 (9,7)、(9,8)
  空）——模型把罕见布局拉回标准开局先验：真 R 判 N（(9,7)）、真空判 R（(9,8) 幻视）。
  (0,7) r>n 对称位 v45 已灭
- **判定口径**：`full`=错 0 格帧数（错 1 格即帧败）、`total_err`=错格总数；底片=
  cnvcs 象棋特级大师模拟器对局 screencap（build_eval.py 构建，真值三源交叉）
- **口径红线核查=干净**：bench_hot_transplant.npz 源帧是 real_frames_labeled.npz
  （450 帧打谱库），非 bench 帧；bench 帧在训练侧唯一用途=选点评测（帧不进梯度）；
  annotate_real.py 用的是 bench 几何参数（SCALE_CORRECTIONS）而非图像——分布匹配，
  非帧级入训
- **nano 满分主因=域内针对性数据**：CCH 上游 Swin 结构（10.85MB，容量 5 倍于我方），
  训练分布恰好覆盖 cnvcs 屏幕域（该域 99.7%，渲染域仅 95% 级、四轴 0.70~0.81 反被
  我方 v45 超越）——是数据优势不是结构优势

## 二、v46 主攻（三线）

### A 线：zfk+efbok 双弹药接入（主变量，数据轮）

1. **zfk 先**：新建转换/裁片脚本（YOLO txt→裁片→开局标准位换子自证 QC，映射抄
   class_map_16；入库前 md5 去重）→ `data/zfk_raw_patch_lib.npz`；预估 28302 框 →
   QC 按 VN 83% 基线 **约 2.3 万枚**（近重复会压缩有效增量）
2. **efbok 随后**：整图 resize 38×38 直入 QC 队列；马/炮/车做红黑双向自证（红位黑位
   各贴一次，谁过 argmax+conf≥0.65 归谁，双过/双不过弃）→ `data/efbok_patch_lib.npz`；
   预估入库 **5000~6500 枚**
3. **多库合并**：--extra-lib 参数 list 化（或先合并 npz）→ 重跑 augment_roboflow_patch.py
   再生 transplant shard0/1 → 训练侧 --real-npz 零改动并列
4. 判据：real17 21→**≤20 核心线**；炮位专项观察 App 域 (7,1)/(7,7)/(8,1)/(8,7) 四错
   是否消失

### B 线：bench 热格移植 v2——组合补向（数据侧同族，副变量）

1. **"R 移位组合"反面证据构造**：bench_hot_transplant v2 在 real_frames 池帧上新增
   TARGETS 组合——「R 从 (9,8) 移开（擦除）+ (9,7) 落 R」成对样本，直击 c1BAKABR1
   布局先验；沿用帧内同色 patch + teacher(nano) QC≥0.55 机制（口径安全：源帧非 bench）
2. **登记不实施**（后续选项）：cnvcs 同型局面重截屏（需模拟器摆局面，工程重）；
   (9,6)-(9,8) 三连格组合加权（v44 E3 跷跷板前科，须带四轴防守门）

### C 线：门结构与防退化

- gates 按 v45 实绩滚动：四轴 -0.5pt 防守（0.8378/0.8376/0.8522/0.7454）；real17
  gen_best ≤20（核心线）、human_best ≤18 不退；total gen_best ≤41、human_best ≤37
  不退；bench 双口径 ≥7 不退；**int8 双门维持 ≥6**（bench_int8 语义 v46 起恢复独立，
  双基座导出顺序已修）
- 训练侧：init-from v45/gen_best + seed 2031 + 超参/early-stop 全沿用（三连甜点
  300~450 步，patience 10 自证够用）

## 三、防退化预注册

- 评测集永不入训铁律重申：bench 10 帧与 human26 26 帧的任何像素级衍生物不入训；
  v2 热格移植源帧仅 real_frames 池
- A 线新库全部过 teacher QC（nano argmax+conf≥0.65）才入库，K/k 永不入库（防双帅
  BAN 沿用）；efbok 双向自证双弃可接受
- B 线 v2 组合样本若 teacher QC 通过率异常（<50%）即弃，不硬凑
- gen 域跷跷板防守：四轴 -0.5pt 门为硬门，实物域增量不得以泛化轴倒退换取
